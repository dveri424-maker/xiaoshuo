# 第018章 两天前的声音

“扬娃，是爸。”

父亲的声音停了一下，紧接着是一阵很重的杂音。

“你妈已经走了。”

林扬一把抓住卫星电话的听筒。黑色塑料在他掌中咯吱一响，接缝向外张开。唐蕊立即按住他的手背。

“松一点。”

林扬把手指放开。听筒里空了两秒，父亲的后半句话才断断续续传出来。

“跟社区往安州走了。涪江的水涨得快，取水点也不对，家里不能留。你要是收到，别顺长江干线回来。听见没有，别走长江线。”

电流声盖住了几个字。父亲又说：“我这边……”

留言到这里断了。

林扬盯着屏幕。那条语音下方标着日期，正是两天前。播放键还亮着，旁边没有回拨，也没有接通标记。

他按下重播。

父亲先叫了一声“扬娃”，说到“我这边”时，声音又在同一个地方断掉。林扬拖动进度条，停在最后四秒，听筒里只有一阵刮擦声。

“电不多了。”严国栋看着电池箱上的指针，“再播，别的消息就开不了。”

门外已经有人拍铁门。

“该轮到我们了！”

“我儿子在江北，帮我打一个！”

“刚才那条说涪江，南京的消息呢？”

铁门每响一下，窗台上的天线接头就跟着抖。严国栋伸手按住线，没去开门。罗佳把值班桌拖到门后，桌腿抵住门板，外面的人才推不开。

林扬又按了一次最后四秒。

刮擦声里像有半个地名，又被一串尖锐杂音截断。屏幕右上角的电量从两格掉到一格，严国栋直接伸手盖住播放键。

“听不出来。”他说，“再按也是这四秒。”

林扬没有把他的手推开。他把听筒放回底座，接缝已经被捏出一道白印。

唐蕊从药包里拿出一卷窄胶带，把听筒缠了两圈。“还能用。别再握这里。”

林扬转头看向她。“安州在哪边？”

罗佳把湿透的校园地图摊在桌角。图上只有仙林校区和周围几条道路，最西边到绕城公路便断了。她沿着图边摸到绕城公路，手指停了下来。

严国栋从工具包夹层抽出一本旧公路图册。封面沾着机油，书脊已经开裂。他翻到江苏页，把仙林的位置圈出来，又向西翻了几页。

“安州在绵阳西北。”他说，“你要先出南京。”

公路图上，一条条红线从南京向西伸出去，穿过城镇、江面和大片低地。林扬的手指停在仙林，往西移到第一处过江通道。地图上只有半个指节，窗外那条通往校门的路却已经被蓝雾截断，连一张病床都要贴着停车线推过来。

他继续向西划。手指跨过安徽、湖北，再沿山地转向四川。图册翻了六页，才碰到绵阳。

杜强靠在窗边看了一会儿。“你靠腿跑？”

林扬合上图册。“靠腿先出不了南京。”

“那就跟体育馆的人走。”杜强说，“收音机里提过北门车队。能开的车，多半都往那边送。”

严国栋拿起铅笔，在校园地图上圈住医院和体育馆。北面的主路已经被蓝根和弃车堵死，铅笔尖便向南绕过医院草坪，从两栋宿舍之间穿过去，最后接上体育馆东侧的小路。

“药车能走这边。”他说，“中间有段台阶，到了那里要抬。”

罗佳把地图转向自己，记住宿舍楼编号，又在那段台阶旁画了一道短线。

门外又有人撞桌子。桌腿在地砖上挪了一寸，罗佳用肩膀抵住桌沿。抱孩子的女人隔着门喊：“路线消息读完没有？我只想知道江北还能不能去。”

严国栋重新坐到电话旁，翻开刚才的值班本。第一页写着涪江水质异常，下面是那句没有头尾的“长江干线”。他把屏幕上三条消息的时间抄到纸上，贴在门后。

“开门吧。”林扬说。

罗佳把桌子拉开。门刚开一掌宽，外面的人便一起往里挤。林扬站到门缝前，脚抵住门底，只让抱孩子的女人先侧身进来。

“先看本子。”他指了指桌面，“电话接不通。谁拆电池、拔天线，谁也听不到。”

女人看完值班本，嘴唇抖了两下。“江北呢？”

严国栋摇头。“没有。”

她没有再问，把手机号码写在空白页上，又在后面添了儿子的名字。后面的人照着她的样子排到墙边，有人留下地址，有人只留一个号码。没人再往电池箱前冲。

高个男人还蹲在墙角。先前被他收走的药和手机已经领回大半，桌上只剩两盒没人认领的止痛片和三部进水的手机。唐蕊把止痛片放进公共药包，严国栋把手机号码逐个抄到值班本后面。

林扬把公路图册推给严国栋。“路线消息来了，先记在这上面。”

“你不带走？”

“我去体育馆看车。这里有人来，就让他知道我们往哪边走。”

严国栋抬头看了他一眼，把图册压到电话底下。“我等到这格电用完，再把天线和工具带过去。”

林扬从值班桌旁拿起自己的帆布包。地质罗盘还在内袋，铜壳贴着包底。杜强把手摇收音机从背包外层抽出来，扔给他。

“你要找车，先听听那边还在不在。”

林扬拧动摇柄。收音机发出一阵长长的电流声，旋钮转过校园应急频段后，里面断续响起一个女人的声音。

“就近前往……重复，就近……”

后半句被杂音吃掉。林扬继续摇了十几圈，同一句话又从头响了一遍。没有体育馆，没有车辆，也没有新的时间。

他关掉收音机，塞进帆布包外层。

唐蕊没有立即让他走。她从食物箱里取出两块压缩饼干，连同剩下的小半瓶盐水一起塞给他。林扬把饼干掰碎，就着盐水咽下去。胃里的空痛压下去后，他把水瓶还给唐蕊，只留下一层瓶底。

唐蕊给抱孩子的女人留下一小包退烧药，随后把药包重新背到胸前。罗佳把校园地图叠好，撕破的西角夹进折缝。杜强拎起钢管，高明远和保安把剩下的食物、氧气瓶分到两辆药车上。

“你真要回绵阳？”罗佳问。

“回。”林扬扛起最重的纸箱，“先去看车。”

他推开门卫室铁门。下午的光已经偏到医院楼顶，蓝雾压住了他们来时的停车线。罗佳按着地图走在药车前面，先带人转向医院南侧的草坪。

众人刚把药车转向西南，地面忽然传来一阵连续震动。

不是弱电间里的低响。声音更硬，一下接着一下，从大学城北面的道路压过来。林扬放下纸箱，踩上门卫室台阶向北看。

一股黑烟越过宿舍楼顶。紧接着，第一声柴油机的轰鸣撞进校园，后面还有三台发动机跟着响。
