# 第005章 别替我答

松岛的手卡在门缝外，腕骨上那三个字还在往上爬。

已代答。

黑墨钻进皮肤，爬过青筋，停在袖口下方。松岛在门后喘得很急，门板每动一下，他手指就在门框上刮出一道白痕。

林扬蹲下去，没有碰那只手，先用断箭把校牌拨到脚边。校牌正面是松岛健太，背面空着，边角的牙印里塞着湿纸屑。

女生缩在他身后，声音轻得发颤：“是松岛君吗？”

门后那只手猛地一抖。

林扬回头看她一眼：“别替他答，也别替我问。”

女生立刻捂住嘴。

门内传来松岛的声音，断断续续：“林君……我没有办法。它刚才点名，我听见有人在里面哭。她说只要帮她答一次，她就开门。我以为……我以为只是让她安静。”

林扬没骂他，先把校牌翻到灯下：“名字。”

“我不知道。”松岛声音压得发扁，“她一直哭，说自己没有答到，说三楼很冷，说十七番不是她。”

广播在四楼天花板里沙了一下。

这一层没有喇叭，声音却从每一扇门后漏出来，细密地刮着耳朵。

“松岛健太。”

松岛的手指猛地扣紧门框。腕上的“已代答”往上窜了一截，钻进校服袖口。他张嘴要回话，林扬一把用断箭横住他嘴前的门缝。

“别答。”

“可是不答会被拖走！”松岛嗓子都破了。

“你答了也没见被评优秀学生。”林扬把校牌踩在鞋尖下，眼睛盯着门里的黑，“你替谁答，它就找谁。现在念你全名，账已经挂你身上了。”

门内忽然安静。

紧接着，一只脚从黑暗里滑出来，抓住松岛脚踝。

那不是手。

一截湿透的学生裤管贴着地面，裤脚里伸出五根发白的脚趾，趾甲被磨掉，肉翻在外面。再往上，一个人影从门内桌椅下爬出来，脸埋在地上，嘴里塞满湿纸。纸团从他唇缝里挤出来，上面全是涂黑的名字。

他抓住松岛脚踝往里拖。

松岛尖叫出来，声音刚出喉咙，广播又念了一遍。

“松岛健太。”

林扬肩伤一抽，半边手臂差点没抬起来。他咬住牙扑过去，用断箭扎下去。

箭尖钉穿松岛袜边，扎进门槛木缝。

松岛的脚被定住半寸，整个人却被拖得往下滑。地板上蹭开一道红，袜子里的皮肉被扯破，血线拖进门缝。松岛疼得眼泪鼻涕全下来，手死死扒着门框，指甲边翻出血。

林扬一只手按住断箭，另一只手拽住松岛后领：“说。你听见什么名字？一个字也算。”

“藤……藤……”

广播里的杂音猛地炸开，盖住后面的声音。

门内那个嘴里塞纸的人影抬起头。脸上没有眼睛，只有被纸撑到裂开的嘴。他从喉咙里挤出含糊声音：“替我答……替我答……”

女生往前一步，又被林扬抬肘挡回去。

“谁答谁倒霉。”林扬额角全是汗，声音还压得住，“你要救他，就把校牌捡起来，别看门里。”

女生弯腰去捡校牌，手抖得厉害，捡了两次才抓住。

松岛脚踝那只脚趾继续往里拖，断箭被压得弯了一点。木缝发出细响，箭尖周围渗出黑水。林扬肩上的伤被牵开，血从袖子里滴到校牌上。

门缝里的黑水碰到血，立刻冒出一串小泡。泡沫里浮出几个残字，答、到、代。它们绕着断箭往上爬，箭杆上的黑墨被顶开，露出一截木头本色。

林扬看见那截木色，膝盖压得更死，把断箭往松岛袜边再推半寸。

松岛惨叫，脚踝却没继续往里滑。

“疼就忍着。”林扬声音发哑，“能疼，人就还在这边。”

门里那团东西听懂了，五根脚趾突然松开松岛，转去抓断箭。林扬等的就是这一下。他把校牌用鞋尖踢给女生，另一只手猛地拔箭。黑水扑空，门槛上的纸字全挤成一团。

女生抱着校牌，手腕抖得厉害。她低头看见校牌背面空白处浮出一点黑墨，嘴唇张开，又硬咬住。

林扬没有回头，只吐出两个字：“忍着。”

她把话咽下去，眼泪砸在校牌上。

松岛哭着喊：“我只答了一声！她说没人帮她，她就会一直待在里面！我真的不知道！”

林扬把断箭重新压回门槛：“她让你怎么答的？”

“到……她让我说到。”

门后的人影突然加力。

松岛半只脚被拖进门里，袜子撕开，脚背上浮起黑字。已代答三个字顺着脚踝往上爬，爬过的地方皮肤发白，血珠渗出来又被墨吃掉，只剩一圈发皱的皮边。

林扬把资料袋甩到地上，湿照片滑出来。他用鞋尖把照片踢到门缝前。

照片上，三浦结衣抱着白鞋站在最后一排。林扬名字旁那张椅子还空着。湿纸刚贴近门缝，门内的人影动作顿了一下，嘴里的纸团往外掉了半截。

林扬抓住松岛校牌，按在湿照片边上。

“你不是松岛。”他冲门内那团湿纸开口，“你要松岛替你答，就把你的名字露出来。别拿别人的校牌要账。”

门内黑暗翻了一下。

嘴里塞纸的人影猛地抬头，喉咙里挤出一串破碎音节。不是松岛的名字。第一个音仍是藤，第二个被广播杂音咬断，最后一个落得很轻。

央。

林扬眼皮一跳。

松岛也听见了，整个人抖了一下，差点又开口。林扬按住他后领，往外一扯。

“别替她答。”

门内人影暴起。湿纸从嘴里喷出来，糊在门槛上，纸上密密麻麻全是“到”。那些字一碰地板就往松岛脚背爬。

女生这回没喊。她咬着牙，把松岛校牌用力砸在门框上。

啪。

校牌裂口卡住门缝，湿纸被挡了一下。

林扬趁这半息，双脚抵住门框，双手拽住松岛后领，伤口里的热血一下涌出来。他眼前黑了黑，还是没松。断箭被他用膝盖顶住，箭杆咯吱一声，终于把门槛里的黑水压断。

松岛被他硬拖出来，后背撞上走廊地板。

门内那只脚没松，拖着一截袜布和血肉缩回去。湿纸人影趴在门缝后，嘴里还在挤纸，声音越来越低。

“替我答……替我答……”

林扬喘了两口，才把断箭拔出来。箭尖上挂着袜线和黑纸。松岛抱着脚缩在墙边，脸上没有一点血色，腕上的“已代答”停住了，但没有消失。

广播没再念松岛全名。

走廊尽头，那只坏钟的指针往前跳了一格。

林扬捡起校牌。正面的“松岛健太”裂开一道细缝，牙印里的湿纸被血泡开。背面原本空着的地方，慢慢浮出一行字。

藤原真央。

松岛看见那几个字，嘴唇抖了几下：“我……我没有听清她的名字。”

“现在听清了。”林扬把校牌塞进资料袋，掌心被校牌冷得发木，“下回有鬼让你帮忙答到，你先问它是不是包售后。”

松岛没笑，女生也没笑。

门里那团湿纸轻轻敲了一下门板。

一下。

又一下。

和楼上点名册的声音连在一起。
