# 第050章 路牌张口

铁背的话刚落，桥螳的右前肢便从油料车上方斜着扫下来。

路霸们原本围在外侧车道，镰肢扫过来时，最前面那人还举着铁棍。他看见前肢的影子压到胸口，才往左躲。镰尖没有碰他的脸，却夹住了他举起的铁棍。

高频震动沿铁棍传到他双手。男人的虎口先裂开，接着两根手指被震得脱开棍柄，血和断指一起落进黑路毯。他惨叫着往后退，桥螳没有追他，前肢反手一收，又把油料车后门夹出一道斜裂口。

油料车里的人全伏下去。梁舟将反光板压到车门下沿，板面朝上，正好把桥螳腹部那片暗黄的甲壳映进林扬眼里。

“别让它把门切开。”梁舟说。

林扬踩着蒋成撒出的灰线绕过中巴车头，右手提着撬杆，左手从腰后抽出地质锤。桥螳立在油料车与废车之间，后足踩住一辆轿车的车顶，反光翅叶贴在歪路牌旁。它每次抬前肢，路牌都会跟着晃，在远处看去仍像一块被风吹歪的标志。

蒋成跟到中巴前杠外，掌心贴地摸了两下。

“你脚下热。”他压低声音，“再往前半米，下面是空的。”

林扬停在灰线尽头。面前是一块被黑路毯盖住的导流岛，右侧是油料车，左侧是歪路牌，桥螳的两条前肢正好把这条缝封住。正面冲过去，镰肢先到；从黑膜上绕，脚会先陷。

废车旁忽然有人把油桶滚了出来。

铁背的右腿还被黑膜包住，裤腿从膝盖往下鼓成一团。他双手扣着硬路肩边沿，肩背一拱，竟把陷住的腿连着一大片黑膜拖出半截。黑膜死死黏在裤腿上，往外冒着热气。

杜强一手按住油料车后门，一手指向护栏缺口下方：“老马和这批油只能先顾一个。没油，四辆车都走不了。”

桥螳的前肢重新抬起，护栏下的拖车钩滚到林扬脚边；油桶提手被铁背的撬棍勾住，收费亭方向又传来孩子的哭声。林扬踩住拖车钩，转身朝护栏缺口看去。

“他出来了！”杜强喊。

铁背拖着那条腿扑向油料车，撬棍从下往上挑。他没去开门，先把撬棍伸进被桥螳切开的缝里，勾住最外侧的油桶提手。

“油桶！”韩东抬手。

梁舟正要从车门旁扑出去，林扬先把地质锤扔给他。

“照它腹下。”

梁舟接住锤子，反光板却没松。他用膝盖顶住板边，将板面朝路牌方向扭了一下。收费站顶棚破口漏下一束白光，白光被反光板折到桥螳腹下。那片暗黄甲壳被照亮，边缘有一条弧形缝，随着它抬肢而张开。

桥螳的翅叶立刻转过来。它没有看林扬，先把一只镰肢伸向反光板。

“现在。”梁舟说。

林扬先抬脚踹向歪路牌的底座。

路牌本就被前肢顶得松动，底座受这一脚，整块牌子朝桥螳腹下砸过去。桥螳的左前肢立即横过来挡，镰尖穿进牌面，蓝底铁皮被夹成两折。它腹部为了抬开路牌，短暂离开了废车顶。

林扬从导流岛边沿踏出一步，右脚踩在梁舟反光板映出的那道白光里。黑路毯在他鞋边鼓起，他没有往前踩第二步，而是将撬杆横插进桥螳右后足旁的车窗缝，双手向下压住。

车窗玻璃碎开，撬杆卡住后足关节。桥螳要抽腿，腹部便被路牌拖得更低。

林扬顺着撬杆贴近，地质锤砸向腹甲边那条弧缝。

第一锤砸开一片黄甲，里面没有血，只喷出一股烫人的白汽。桥螳的镰肢立刻回剪，林扬松开撬杆，肩膀擦着油料车轮眉向后退。镰尖从他胸前掠过去，切开了他外套前襟，衣料落进黑膜，瞬间被黏住。

桥螳的后足还卡在车窗里。它扭身去拔，腹部的伤口向外张开，白汽夹着黏液落到黑路毯上。墨黑表皮没有躲开，反而沿着热汽往桥螳后足爬。

蒋成看见那一幕，朝林扬喊：“它怕路凉，伤口在冒热！”

林扬伸手接住梁舟扔回来的地质锤，正要再近，铁背已经将油桶从车门缝里勾了出来。

那只油桶撞到地面，桶盖松开。柴油洒出一线，正流向桥螳受伤的腹部。

铁背拖着裹满黑膜的右腿往外退，咧着嘴说：“你打怪，我拿油。各凭本事。”

林扬回头看他一眼。“你没这个本事。”

他抡起地质锤砸向油桶旁的水泥隔离墩。锤头砸碎墩角，半块混凝土翻进柴油里，将油线截成两段。铁背刚要跨过去，林扬已经借着隔离带跑到他面前，一脚踹在他拖着黑膜的右膝外侧。

铁背的腿向内折。黑路毯裹住的膝盖没断，左腿却被这一下踢得失去支点。他整个人翻进导流岛边的裂缝，背脊砸在沥青上。黑膜顺着裂缝涌上来，先黏住他手里的撬棍。

“拉我上去！”铁背朝同伙吼。

那两个路霸望着桥螳腹下翻起的黑膜，又看见林扬站在裂缝外，谁也没敢靠近。

桥螳终于拔出后足。

它没有再去夹油料车，而是将两条镰肢贴到地面，撑着受伤的腹部退回歪路牌后。路牌被它拖出一串刺耳响声，蓝底铁皮一路刮过黑膜，最后竖在收费站外侧最窄的车道口。

它把路口堵住了。

蒋成站在灰线边，掌心贴着地面，额头上的汗顺着鼻尖滴下去。

“它没走。”他说，“它把油库那边守死了。”

收费站后方还有一道矮护栏。护栏外原本是通往油库的维修便道，便道中间横着一辆翻倒的小拖车，车斗里散着冷料袋和一捆拖绳。刚才桥螳拖走路牌时，左侧镰肢扫过护栏，栏杆被切出一道缺口。

缺口下面传来金属摩擦声。

“有人吗？”

声音很闷，像从车底传出来。

蒋成脸色又白了一层。他沿灰线跑到护栏边，探头往下看。翻倒的小拖车压住一个穿养护服的男人，男人半个身子卡在车斗和护栏之间，右手还抓着拖车钩。桥螳的左前肢正从护栏缺口探下去，镰尖距离他的脸只有一尺。

“老马！”蒋成喊。

男人抬不起头，只把手里的拖车钩往上举了一下。“别下来，下面是热的。”

桥螳听见声音，前肢又往下一压。镰尖钉进小拖车的车斗边缘，铁皮在震动里卷起，车斗底下的男人被震得咳出一口血。那根拖车钩从他手里滑出去，沿着斜坡滚到林扬鞋边。

林扬弯腰捡起钩子，先看护栏下方。小拖车侧翻在维修便道的低处，车斗压住老马腰腿，黑路毯从便道排水口里漫出来，已经贴到拖车后轮。桥螳站在护栏内侧，后足踩着歪路牌，前肢刚好守住唯一能下去的缺口。

“它不只守油。”梁舟说。

“它守热。”蒋成盯着小拖车下冒出的白汽，“拖车刚熄。”

林扬把拖车钩扣在自己腰后的皮带环上，又将另一端递给杜强。

“我下去。”

杜强没有接绳子。“它两把镰刀都在口上。”

“你守上面。”林扬把地质锤插回腰后，“它先动，你拉我。”

铁背还躺在裂缝里。他的右腿被黑膜裹住，嘴里却发出一声低笑。

“你下去就是送给它切。”

林扬看都没看他。他抓住护栏缺口的断面，双手向两边一掰。弯折的栏杆没有被拉开多少，却发出一声闷响。桥螳的复眼立刻转向他，左前肢从老马头顶抬起，镰尖在半空停住。

护栏下面，老马的手又摸到了那只拖车钩。他没能抓住，只把沾血的手掌按在翻倒车斗上。

“林扬。”蒋成低声说，“别让它再夹一次。”
