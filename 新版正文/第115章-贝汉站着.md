# 第一百一十五章 贝汉站着

贝汉那只越过书记员肩膀、伸向副页盒的手，停在半空里没有落下。

盒子卡在矿车板内侧的窄铁皮上，盒盖没落锁，外头绕着一条布带，结头正压在伊莱亚斯左手指下。他坐在车板最外沿，一条腿垂下去，靴跟压着碎石。虎口的新绷带被木沿磨得发紧，方才林月兰打的结正好硌在掌背上，疼得他有点想把手松开；可一松，就显得这小盒子比它里面那张副页还要金贵。

里面不过是一张副页、一张撕痕拓纸，外加书记员抄过的编号。可自从那张纸进了现场记录，贝汉盯它盯得比盯现银还紧。

“韦德。”贝汉先把手收回去，装作方才只是随手一比划，“这是图森旧辖的临时接收命令。副页和矿车都该交县车保全。你再扣着，才叫真把事情闹坏。”

他把一张盖了蓝蜡印的命令抖开，纸角在风里啪啪作响。县车护卫立刻往前凑了半步，律师也把文件夹夹到腋下，摆出一副终于轮到他们讲道理的样子。

围线外的矿工却没让开。这些日子，他们看够了旧辖的命令和矿方的账页，也看出一点门道：谁急着把纸塞到韦德面前，多半就是要把工资箱、尸体或证人带走。

伊莱亚斯抬眼看了贝汉一下。

那张命令纸边被风一掀，旧墨和封蜡混出一点潮湿的怪味。蜡印缺口透出一丝冷意，贴到他按住盒盖的手背上。伊莱亚斯没盯它太久，只看了看命令抬头，又看向矿车旁那张小桌。

书记员刚换过笔尖，脸色仍有些白。

“把命令拿到小桌边，你自己念。”伊莱亚斯说。

贝汉以为他要接令，嘴角刚往上抬，便听伊莱亚斯补了一句：“别递给我。”

“什么？”

“你带来的命令，你念给大家听。”伊莱亚斯抬了抬按着副页盒的手，“我坐着，是因为这盒子还在现场保全里；你站着，是因为你说它该换主人。话总得说全，别只挑能唬人的那一行。”

贝汉脸上的肉僵了僵。

他原以为只要把旧辖的名字搬出来，货栈边这些矿工便会退回尘土里。谁知眼前这个外来枪手坐在矿车板边，连声音都不高，反倒把他推到了书记员那张巴掌大的桌子前。

那桌子小得可怜，桌腿还垫着两块不一样厚的木片。贝汉若想把命令铺平，便得弯腰；若不弯腰，纸就被风卷成一团。县车护卫站在一旁看得尴尬，想替他接一把，又不敢越过韦德的视线。

“念啊。”艾达忽然在绳外说。

她没往前挤，手仍按在工资箱外壳上，煤灰洗得差不多了，指缝里却还留着一点黑。她说完便闭了嘴，只用下巴点了点那张命令：“先把矿工的工钱送到哪儿，念清楚。”

贝汉横了她一眼，才低头念道：“兹令图森旧辖临时护卫，自塔夫纳特矿口至墓碑镇界外之矿路，接收未入现场勘验之散货、私账残页及相关车载物，以待旧辖复核……”

念到这里，他的声音顿住了。

货栈侧线离墓碑镇界外很远，连最没见过地图的矿工都知道，县车若想照这道命令办事，得先把矿车拖回矿口。

年轻护证人没忍住，低声嘀咕：“谁真能让这车自己回矿口，我俺也去当矿主。”

老矿工立刻给了他一胳膊肘：“少出声，听贝汉先生把路段念完。”

几个人憋不住笑，笑声不大，却比骂人更让贝汉难受。他捏紧纸边，指节泛白：“文字上的路段可以按实际运输线解释。”

“行。”伊莱亚斯说，“继续念。尤其是你刚才没念完的那句。”

贝汉盯着他，没动。

克拉拉站在车板右侧，怀里抱着刚印好的小样纸。她的伤手不能用力，便用未伤的那只手压住纸角，纸上只印了书记员已经写入的标题和物件名。她没替谁开口，只把小样纸往风里举高了一点，旁边报童立刻看清了那行字：货栈侧线证物保全与现场勘验。

贝汉的目光从铅字上滑过去，又撞见露丝。

露丝站在另一头，旅店登记副页锁在掌心，后门钥匙垂在腕间。她没再挡在证人前面，只安静看着他。那扇后门放出过几名证人，也留过几份口供；贝汉若想把登记副页当成“旧辖散货”带走，得先问问那些从门后活着出来的矿工答不答应。

再往右，是莉迪亚。她把纸带匣搁在脚边，匣盖扣得严实，手心压着经手号抄件。她没抬头，只把抄件翻到发报时辰那一页。贝汉知道那封伪电就是从这一串小孔里露了馅，喉结不由滚了一下。

四个女人都站在各自守下来的东西旁边，没有谁挤到书记员桌前。露丝守着登记副页，克拉拉拿着样纸，艾达压住工资箱，莉迪亚翻开纸带时辰页，外人想靠近车板也得先看看她们的脸色。

书记员小心问：“贝汉先生，命令后文还要不要写进记录？”

“当然要。”伊莱亚斯替他答，“原样写。别替他省墨水。”

贝汉脸色发青，只得继续往下念：“……凡已由现场勘验者，应留于原处，待临时书记员注明接收人、交付时辰与保全理由后，方可移置。”

最后几个字被他压得很低，几乎听不清。

书记员却听得很清楚。他原本握笔时还在发抖，此时忽然坐直了一点，先把贝汉念过的前半段写下，又翻到刚才记录矿车封条的页码，认真核起“已由现场勘验”几个字。

“矿车验过封，工资箱清过，副页记过编号。”他一项项念，声音越来越稳，“接收人栏还是空的。”

贝汉立刻道：“县车可以接。”

“哪辆车，哪个护卫接手？把名字报上来。”伊莱亚斯问。

县车护卫里有个胡子最浓的家伙下意识往后缩，正好踩到车链，铁链哗啦一响。他把靴跟挪开，脸色也不好看：“我只负责赶车，不负责接矿车。”

旁边的人忙道：“我是护卫，不管账页。”

第三个连忙摆手：“我没带接收册。”

贝汉转头瞪他们，脸色发黑。伊莱亚斯却没笑，只伸手把副页盒往车板内侧推了半寸。

“那就还在原处。”他说，“你今天能带来一张错路段的旧辖命令，算你没白跑。至于车和副页，等有人肯把姓名、时辰和为什么接收写明白，再来同书记员谈。”

他抬手示意护证人把命令夹进记录副本中，没碰原件，只让书记员照着抄明抬头、路段和那句“留于原处”。贝汉想抢回纸，刚迈出一步，伊莱亚斯便让银柄左轮从枪套里露出一线，叫他看清再往前会有什么。

贝汉脚下顿住，鞋尖悬在碎石上，进也不是，退也不是。围线外没人喝彩，反倒是那个先前笑矿车会走的年轻人低下头装模作样咳嗽，憋得肩膀直抖。

“原件在你手里。”伊莱亚斯说，“抄件在记录里。你怕什么？”

贝汉没答。他把命令一把抽回去，折得过紧，蓝蜡印险些裂开。他手腕发抖，却还把纸塞回内袋。

资本律师看见这一幕，知道县车这条路已经压不住人，立刻换了副腔调。他从文件夹深处抽出一只窄信封和半张债券缺页，动作比方才慢得多。

“既然贝汉先生的命令不适用于眼下现场，”他说，“那么资本方也应避免让无关私函继续占用勘验。债券缺页与那封白手套来信，申请撤出。”

他把两样东西按在文件夹上，手掌压得很紧。

伊莱亚斯看着那副白手套，指节轻敲副页盒盖。

“撤？”他问，“好。下一页给他。”

书记员抬起头，笔尖悬在纸上。

货栈侧线的风突然又大起来，吹得债券缺页露出一道参差断边。那封信没有落款，信封蜡印上却还留着半截白手套压出的纹路。律师立刻用掌心盖住断边和蜡印。

伊莱亚斯没有叫人按住他，只看向书记员：“写。有人要把东西带走，就把他怎么带来、为什么带走，一并留在这儿。”
