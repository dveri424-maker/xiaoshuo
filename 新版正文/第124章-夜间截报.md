# 第一百二十四章 夜间截报

远处的车钩又撞了一下，声音闷得像有人在黑夜里扣上了一扇铁门。

乔纳带回来的半截纸带压在木尺下，边缘参差，煤油味还没散。调度簿最上面那页原电被人抽走，说明对方不是临时起意，更不是哪个夜班小子顺手拿去擦灯；他们早知道那页纸会要命，才赶在韦德的人到车站前，把它从柜缝里掏了出去。

“原电未必还在车站。”莉迪亚说。

她仍坐在电键前，速记本贴在肘边，夜班钥匙收在皮套里。费尔曼留下的铜帽和跳线已经放进铁盒，护证人守着盒子，谁也没有把它们当成一锅刚出炉的金子来传手。

“你听见什么了？”伊莱亚斯问。

“不是听见，是少听见。”莉迪亚将半截纸带同先前的情书暗码并在一起，“正常换挂，十一号封厢要向本森回一记接收码。它没回。西边侧线却多出一记短促的灯号，像是有人叫另一边来收东西。”

克拉拉抱着手臂站在油灯旁：“你们铁路人递一张纸，也要把它写得像偷情？”

“他们没有偷情。”莉迪亚道，“他们在偷能让人上绞架的东西。”

伊莱亚斯看着墙上的线路表。七号木材车先过北岔，三号空煤车作遮掩，十一号封厢藏着不入册的护卫，五号车在西边侧线等机车推送。大多数人会盯着十一号，觉得原电既然牵着私兵，必定要塞进带枪的人手里。

可真正要带走纸的人，反而不能坐进那节车厢。

车厢一旦被查，封厢里的护卫能装成押运；从调度簿里抽走原电的人，却没有任何一条轮班记录能替他解释。对方只能把纸交给一个看似有资格在夜里提灯、开门、过岔道的人，再让那人从三号空煤车的阴影里穿过去。

“乔纳。”伊莱亚斯道，“带护证人去西侧线。别堵车门，也别把谁从车上拽下来。盯着三号车和五号车之间的路，见到提调度封袋的，先看他的手，再看他的灯。”

乔纳摸了摸下巴：“看手我懂。看灯？”

“正经夜班灯有领用牌，偷纸的人只会带能照路的。”

“要是他带着牌呢？”

“那就看谁给他发的牌。”

乔纳咧了下嘴，把帽檐拉低：“你这人查个电报，比查死人还挑剔。”

“死人不会趁夜里换车。”伊莱亚斯说。

莉迪亚已经把一张写着“十一、五”的窄纸折好，递给乔纳：“我留在这里听接收码。你们看到灯号，不要回灯。回了，他们就知道哪边有人。”

乔纳接纸时，眼神在她脸上停了一瞬：“你一个人在这里？”

“我有门钥匙、护证人和一台会说话的机器。”莉迪亚道，“你有枪，去看车。”

老矿工护证人低咳一声：“机器说话这事，俺也去不明白。不过姑娘说不回灯，那就不回。”

伊莱亚斯没再拖延，带着乔纳和两名护证人从电报局后门出去。子夜前的车站像个没睡醒的巨兽，煤烟贴着低空，铁轨在月光下泛着湿冷的白。五号车果然停在西侧线尽头，车门紧闭；三号空煤车斜在岔道旁，煤斗黑得能把人影吞进去。

他们刚绕到煤车后，站房里便出来两个人。前头那个提着一盏罩灯，后头那个穿铁路护卫的长外套，腰间枪套扣得很严。提灯人手里夹着一个灰油布封袋，走得不快，却把灯提得很低，像生怕照到自己的脸。

乔纳压低声音：“那灯没牌。”

伊莱亚斯看见了。正经领用灯的把手下都挂着黄铜牌，这盏灯只有一截磨得发亮的麻绳；提灯人的右手虎口沾着蓝黑墨油，和调度簿柜缝里的油渍一模一样。

银星之眼在油布封袋边掠过一丝凉意。它没有告诉他袋里是哪张纸，只让他的后颈绷紧，像有人把冰屑顺着领口塞进去。

护卫先停下，隔着煤车喝道：“谁在那儿？”

乔纳正要上前，伊莱亚斯已从阴影里走出，手没摸枪。

“墓碑镇治安官办事。”他说，“把封袋放下，灯也放下。”

提灯人脸色一变，护卫却横过半步，挡在他前面：“铁路夜间交接，闲人不得干预。你要查人，白天带着书记员来；现在动调度封袋，误了车，谁担得起？”

“你担得起？”伊莱亚斯问。

护卫一噎，随即冷笑：“我至少在护卫册上。”

“那更好。”伊莱亚斯看向提灯人，“他呢？”

提灯人把封袋往怀里一收：“我是灯房的。”

“灯房的人为什么从调度簿里取原电？”

那人脚下一滑，鞋跟蹭过碎石，罩灯晃出一片黄光。乔纳没忍住，低声“啧”了一下。提灯人脸涨得通红，想骂又不敢骂，只把灯提得更高些，仿佛灯高一点，便能把自己照成铁路官。

护卫的手落到枪柄上：“韦德先生，您在货栈扣矿车，铁路已经让了。别以为每条铁轨都归您封蜡。”

“铁轨不归我。”伊莱亚斯道，“可从调度簿里抽出来的纸，也不归你腰上的枪。”

护卫拔枪的瞬间，煤车后响起一声车钩摩擦。伊莱亚斯侧身避开枪口，左手抓住对方手腕往下一压，右肩旧伤跟着狠狠一跳，疼得他眼前发白。那护卫本以为他只会摆治安官的架子，手腕被压到车壁上才知道错得离谱，枪口朝天歪去，砰地打碎了煤车边的警示灯。

乔纳和护证人没有扑上去抢枪。乔纳先把提灯人的封袋夺下来，老矿工则一脚踩住滚到铁轨边的罩灯，免得火油泼进煤渣里。提灯人想趁乱钻进五号车底，才迈一步就被煤车滑落的黑灰呛得连咳几声，膝盖一软，正跪进一小摊积水里。

“灯房的？”乔纳拎着封袋看他，“你们灯房现在还管洗脸？”

伊莱亚斯把护卫的枪踢远，没空同他较劲。他接过油布袋，封口的红蜡还温着，压痕却不是货栈或本森的整章，而是一枚缺了半齿的夜班转运印。

“谁让你取纸？”他问提灯人。

那人咬住牙：“铁路规矩，调度副本要跟车走。”

“哪一站接？”

“不知道。”

伊莱亚斯没有逼他回答，只把封袋递给乔纳：“让他自己拆。”

提灯人抬头，脸色更白：“我没权拆。”

“你有权从柜里拿，没权当着人打开？”伊莱亚斯蹲下身，看着他，“那你不过是替别人跑腿。跑腿就把你知道的站号、车号和领用牌说出来，别替一封纸挨枪。”

护卫还想开口，伊莱亚斯回头看了他一眼。那人右手腕已经红肿，枪也离得老远，嘴唇动了动，到底没再拿铁路规矩当盾。

提灯人盯着封袋半晌，终于用沾煤灰的手指掰开蜡口。里面果然不是调度簿原页，而是一份誊抄副本，纸角还留着撕下时的短纤维。最上方写着站号九，下面依次是北岔七号木材车、三号空煤车、十一号封厢与五号西侧线；末尾有一行夜班转运签收栏，接收人空着，领用护卫六人却压着同一枚半齿印。

原电没找回来，可那张副本已经把抽纸的人、换挂的车和准备接手的站全钉在同一夜里。

伊莱亚斯正要让乔纳把纸收好，车站方向忽然传来一记极短的铜铃。

莉迪亚没有让人回灯，却从电报局发来一名报童。小子跑到近前，上气不接下气，递来一张急抄纸：“莉迪亚小姐说，最后一段暗码又响了。对方在问，‘露西’为什么没回信。”

乔纳低头看副本：“这不正好？让她敲回去，把他们钓出来。”

“她说要亲自去西边站台的接线屋。”报童赶紧补上，“那里才发得出他们认的回码。她说不站到那儿，对方不会信。”

伊莱亚斯脸色沉下来。他将那份调度副本折好，递给乔纳。

“带人回电报局，纸不离你手。”

随后他翻身跨过铁轨，朝电报局的灯火走去。隔着半条煤烟蒙住的街，他已经看见莉迪亚站在门内，耳机还挂在颈边，正把皮套往肩上系。

“你不能去。”伊莱亚斯隔着夜色开口。

莉迪亚停住：“再等，他们就断线了。”

“那就让它断。”他看着她，“你可以替我听线，不能拿自己去给他们验线。想用你把人钓出来，先问我答不答应。”
