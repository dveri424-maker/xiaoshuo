# 《未知进化》网文创作工作流

本 skill 负责把项目任务组织为可检查、可续写、可同步的流程。它不另造世界观，所有内容必须服从根目录 `CLAUDE.md` 和当前设定文件。

## 一、事实源

按任务读取，不得引用不存在的旧项目文件：

1. `未知进化_故事总纲.md`：人物、七卷剧情、能力成长、爽点与结局。
2. `未知进化_世界设定.md`：三把锁、迁跃规律、人类表型与社会结构。
3. `未知进化_地理路线.md`：返乡、成都、高原路线和节点选择。
4. `未知进化_物种图鉴.md`：生态链、俗名、结构代价和可利用资源。
5. 任务涉及的当前卷细纲、章节细纲、相邻正文与用户补充。

`未知进化_拆分前完整归档.md`只用于追溯，不作为编辑入口。参考小说只用于分析类型方法，不得作为本项目事实源。

开始前先列出本次真正需要的文件。写单章时不整份复述所有设定，只读取对应卷、当前地点、登场物种与相邻正文。

## 二、通用硬约束

- 类型是末日生态进化科幻，不是无限流、灵异、系统文或游戏异界。
- 迁跃不凭空创造能量和智慧；优势必有同一结构导致的代价。
- 林扬的能力是应激固化，必须符合卷别阶段，不能临战方便进化。
- 林扬能忍、务实、慎于承诺，但眼前有人倒下时行动先于表态。不得把他写成怕麻烦、习惯逃避或冷静计算谁该死；他的迟疑应集中在是否能为许多人保证一条路线。
- 人类不使用职业、等级或技能树；研究院五类表型只是医学档案。
- 新物种按生态链组织，不按小怪、精英、BOSS 排列。
- 胜利解决局部问题，同时改变资源、生态位或后续风险。
- 林扬负责最后距离，但专业结论、工程运转、医疗、组织和跨区校订必须由对应人物完成。
- 北京与四川是平等协作关系，跨区通信必须产生行动后果。
- 正文默认第三人称贴近林扬，不越过他的可知范围讲答案，也不用外部摄像机先替他看清现象。
- 方舟系统是过期授权与新生态的共生体，不写成人格化觉醒 AI。
- 把人物、资源、能力和生态因果留在幕后自检；正文不展示完整证据链、推理链或设计结构。
- 把奇观与林扬的欲望、恐惧和损失放在解释之前。允许误判、信息缺口和长期没有答案。
- 正文默认使用通俗、直接的现代汉语；奇异感由新世界本身承担，不靠生造搭配、拟人化感官和文艺比喻。对白按普通人现场说话的方式写，不加工成主题句或金句。

## 三、任务类型

### 1. 设定或总纲调整

先判断修改属于人物剧情、世界规则、地理路线还是物种档案。输出至少包括：

- 修改目标及读者收益；
- 与现有设定的冲突点；
- 受影响的卷、人物、路线、能力或物种；
- 修订后的明确规则；
- 需要同步的工作文件。

新增设定必须能进入场面。不能只增加名词，应说明它将通过什么现象、人物动作、资源变化或决策被读者看见。

### 2. 卷纲设计

卷纲至少明确：

- 时间范围与地理范围；
- 本卷生存目标及失败后果；
- 视觉主色和核心生态链；
- 林扬起始能力、能力升级、首秀、代价和身份回报；
- 主要人物的独立目标与冲突；
- 旧经验误读如何造成第一笔损失；
- 三至五个小兑现、一个以上中型兑现和卷末公开大兑现；
- 人类取得的设施、路线、知识或制度成果；
- 卷末生态后果和下一卷入口。

卷纲不能只列连续战斗。必须同时推进生存基础、队伍关系、普通人生活与宏观生态变化。

### 3. 章节细纲

每章先写清一句话目标：谁为了解决什么当场问题，采取什么行动，结果让处境发生什么变化。

章节卡建议格式：

```markdown
# 第XXX章：标题

- 时间与地点：
- 视角人物：
- 起始状态：同行者、伤势、装备、食水、车辆、通信
- 本章主目标：
- 本章主要异常或压力线：
- 当场压力：
- 物种痕迹或环境异常：
- 旧经验与误判：
- 关键观察及来源：
- 准备与失败方案：
- 林扬的关键动作：
- 配角的不可替代行动：
- 获得、损失与生态后果：
- 能力和生理债连续性：
- 章末具体钩子：
```

不是每章都必须完整走完“误读、观察、准备、接触”。这四步可以跨章、错序或缺步；事件需要产生行动结果，物种机制不必完整闭环。

章节卡是作者的幕后账，不是正文目录。不得为了逐项兑现章节卡，把物种痕迹、观察来源、准备方案和生态后果依次讲给读者。

细纲自检：

- 是否把多个主要事件硬塞进一章？
- 本章变化能否用一句话说清？
- 信息是否来自角色实际看见、测得、听到或收到的记录？
- 每条信息为何必须在本章出现，它是否改变林扬当场的注意、动作或选择？
- 新增异象、消息或物种是否加深同一条异常，而非另开并列钩子？
- 是否让林扬提前使用后卷能力？
- 是否把专业配角写成报答案工具？
- 章末钩子是否来自本章后果，而非突然投放无关怪物？

### 4. 正文续写

写前执行：

1. 读取对应卷纲和当前场景必要设定。
2. 读取前一章正文；必要时再读后一章细纲，防止钩子撞车。
3. 建立连续性清单：时间、位置、同行者、伤势、适应状态、装备、食水、车辆、物种认知、通信。
4. 确认本章只承担一个主要推进目标，并用一句话写明主要异常或压力线。
5. 把所有准备写入的新闻、群聊、报告、远方消息和新物种过一遍准入检查：不改变林扬当场欲望、动作或选择的，不写。

连续性清单只用于写前校验，不得转换成正文中的盘点段落。

写作时执行：

- 从未解决的动作、后果或需求起笔，不大段复盘。
- 让每句现场叙述从林扬当下的感官、身体、念头、动作或误解中发生。信息没越界不代表视角已经贴身。
- 只报告林扬的外在动作不算进入他的视角。动作应带着他此刻的目的、阻力、身体感或注意变化发生。
- 不先用旁白给出全景和完整异常，再写林扬发现它。从他的模糊不适、局部感知或当场需求进入，不强求他看全或看懂。
- 不靠句句重复“他看见”“他觉得”标记视角，要让叙述的注意力、用词和判断本身属于林扬。
- 只写设定中此刻真正撞到林扬身上的部分。信息可知不代表必须写；无法加深本章主要异常或改变他当场行动的，删除或延后。
- 不用新闻、群聊、家人消息、报告和多个新物种并列展示世界观。远方信息只有同时加深当前异常、击中林扬的具体牵挂或迫使他改变选择时才能进入。
- 先让读者看到奇观、现象与利害；只有下一步行动无法成立时，才给最少的暂时解释。
- 把力量、速度、气味、湿度、坡度、温度、距离和资源写成可感知变化。
- 战斗靠站位、工具、环境准备和临场选择，不靠招式名或能力说明。
- 让人物说当下会说的话；危机中不安排完整设定演讲。
- 允许人物听错、说错、漏看、冲动和做出非最优选择，不替他们补成严密论证。
- 新物种首次出现不同时交代完整机制、弱点、研究名和资源用途；默认一章最多确认一个新生态结论。
- 强画面或关键动作之后直接推进，不追加“这意味着”“他意识到”式翻译。
- 林扬赢时先让胜利与回报完整落地，生理债在战后场面结算。
- 以具体的新处境收尾，例如水压改变、道路断开、手册撤回、车辆缺位、伤口生根或通信恢复。

写后执行：

- 核对字面连续性和设定连续性。
- 搜索本章涉及的人名、地名、物种和物件在相邻章节中的状态。
- 检查胜利获得了什么、消耗了什么、空出了哪个生态位。
- 删除不影响下一步理解的分析句、总结句和证据链，尤其检查段落最后一句是否在重复解释前文。
- 逐场检查是否仍有外部镜头先看清现象、再切回林扬反应，以及他无法感知的全景、背影或身后动静。
- 检查是否有多个同等分量的异象或钩子互相抢戏，以及不影响林扬当场行动的“虽然正确”信息。
- 使用 `novel-de-ai` 与 `human-prose` 的清单复查表达。

### 5. 正文审查

审查按严重度排序：

1. 事实冲突：时间、路线、人物在场、物件归属、伤势、死亡与通信状态。
2. 设定越界：万能迁跃、阶段能力提前、能量无来源、方舟人格化、物种突然全知。
3. 因果漏洞：弱点无观察依据、资源凭空出现、路线无信息就改变、配角无故服从。
4. 场面失效：空间不清、动作不可执行、危险只靠形容词、胜利没有可见结果。
5. 节奏问题：重复解释、过载、回报拖延、章末钩子脱节。
6. 文风问题：作者总结、清单化、工整群像反应、比喻炫技和高频短句。

只审查时给出文件和位置、问题、证据、影响及最小修正建议。用户要求直接修改时，再按优先级改稿。

### 6. 改稿重修

- 先锁定必须保留的剧情事实、能力反馈、人物选择、物种线索和章末接力。
- 局部问题局部修，不为去 AI 味重写整章因果。
- 大幅调整事件顺序前，检查下一章是否依赖原位置、伤势或物件。
- 保留行动所需的最少专业信息；其余可以延后、打碎或不解释，不能为了显得合理补成测量、试验和论证长段。
- 改完重新读取相邻章，确认人物没有瞬移、失忆、复活或恢复得过快。

## 四、生态事件设计

重要物种使用“三次见面”：

1. 痕迹：颜色、尸体、消失的食物、异常声音、设施故障。
2. 误判：人物用旧世界经验处理，付出具体代价。
3. 接触：团队识别结构代价，完成猎杀、驱离、交换或利用，并触发生态后果。

重要冲突使用“四步结构”：误读、观察、准备、接触。设计时还要回答：

- 该生命的能量和材料来自哪里？
- 它在捕食、繁殖、迁徙还是筑巢？
- 它的鲜艳颜色承担什么功能？
- 人类的热、光、噪声、排污和交通如何吸引或喂养它？
- 处理它以后，谁会获得尸体、领地、食物或资源？
- 人类能否将危险的一部分转化为药物、材料、食物或预警？

以上问题只要求作者在幕后知道，不要求人物在正文中逐项回答。正文可以只写林扬当时看见的一角。

## 五、文档同步

修改后只更新真正受影响的工作文件：

- 人物、卷纲、成长、爽点、结局 -> `未知进化_故事总纲.md`
- 灾变、迁跃、人类表型、社会制度 -> `未知进化_世界设定.md`
- 节点、道路、路线选择、跨区联系 -> `未知进化_地理路线.md`
- 物种、生态链、弱点、资源用途 -> `未知进化_物种图鉴.md`
- 章节事实 -> 当前细纲、时间线或正文连续性记录（存在时）

禁止更新拆分前归档。同步后搜索同一关键词的其他出现位置，消除旧版本。

## 六、交付格式

- 创作任务：直接交付目标文档或正文，并简述同步内容。
- 审查任务：问题优先，按严重度列出位置、证据、影响与建议。
- 改稿任务：说明修改范围、保留项、受影响连续性和验证结果。
- 如果缺少决定剧情走向的关键信息，应明确缺口；可以从现有总纲可靠推导的小细节则直接处理，不反复询问。
