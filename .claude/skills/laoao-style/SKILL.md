# 《未知进化》老嗷文风适配

本 skill 用于增强男频网文的推进力与爽点，不是模仿某部作品的专有设定、人物或原句。使用时服从 `CLAUDE.md`、故事总纲和当前章节连续性。

## 一、只取这些口感

1. **麻烦落地快**：尽早给出具体需要、障碍或选择，不先讲一页背景。
2. **主角中心明确**：林扬必须完成关键判断或最后接触，不能在高潮中被旁观化。
3. **低处信息管用**：裂缝走向、风口、坡度、花瓣颜色、尸体耳后根毛、油表和水压能改变行动。
4. **强度可以看见**：门被拉开、追上慢车、看清俯冲、把失联车拖出毒尘，不只说“实力提升”。
5. **动作有回弹**：林扬一动，物种、队伍、设施或路线立即产生可见变化。
6. **收益能落袋**：救下的人、抢回的设备、恢复的水线、修订的手册、获得的权限都要明确。
7. **对白有来有回**：人物围绕当场利益短促交锋，不轮流发表正确观点。
8. **世界值得多看一眼**：新生命先让读者惊奇、着迷或不舒服，不急着归类成敌人与材料。

不取以下方向：

- 官场、内宅、荤趣或纯打脸摆拍；
- 系统面板、技能抽取、等级碾压和掉宝循环；
- 把末日写成只供主角升级的游乐场；
- 配角集体降智或机械吹捧主角；
- 用玩笑消解死亡、资源与选择的重量。

## 逻辑藏在行动后面

- 保住位置、伤势、能力和资源等底层连续性，但不在正文展示检查过程。
- 让人物因为想活、想回家、想救人，或怕一句错误保证把别人带进死路而行动，不要求先完成正确分析。林扬面对眼前求救时应先动手，迟疑主要发生在需要许诺一整条路线的时候。
- 一两个低处信息足以推动动作，不凑齐证据链。人物可以猜错，正确办法也可以只是暂时有效。
- 强画面之后立即让局面继续，不追加“这意味着”式答案。
- “三次见面”、场面骨架和兑现节奏都是幕后工具，不能让读者看见作者逐项打卡。

## 二、林扬的爽点写法

### 1. 外显强化先兑现

第一卷基础强化必须用熟悉尺度展示：

- 四个人抬不动的课桌，他情急之下独自掀开；
- 变形防火门在人流中被他撑住；
- 他数秒穿过走廊救下罗佳；
- 玻璃蛛扑下时，他第一次看清完整轨迹并近身砸穿。

后续升级同样要改变动作方式：主动调用、双态叠加、临战预调和全域过载不能只换名称。每次新能力首秀都要解决旧阶段确实做不到的问题。

### 2. 强不等于全能

林扬的高光最好由团队铺出窗口：

- 高明远找出重复规律；
- 罗佳指出可走方向；
- 严国栋让泵、阀或机车配合；
- 韩东维持撤离顺序；
- 唐蕊判断他还能行动多久；
- 周静送来可复现的失败记录；
- 林扬进入别人无法承受的最后距离。

这样不会削弱主角，反而让他的最后动作更难被替代。

### 3. 赢要被看见

重要兑现至少由一个明确对象见证：被救的同学、整支车队、庇护城防线或短波另一端。见证应转化为后果：防刺外套被交给他、韩东把他调入前锋、队伍等他开口、他获得改线或取消突入的权限。

不要只写群众震惊。权力、资源和关系发生变化才是有效认可。

### 4. 代价别抢高光

高潮中先让林扬完整赢一次。下一场再用高烧、惊人食量、味觉丧失、药物排斥、异常体温和组织损伤结算。

代价要持续，但不要用一句“他赢了，也付出了惨重代价”代替具体后果，更不能每挥一拳就提醒一次寿命减少。

## 三、场面骨架

### 1. 麻烦砸进人物正在做的事

合适入口：

- 林扬刚回到校园，绿化带一夜全开蓝花；
- 众人关窗避毒，却把粉蛾和四十多人锁在一起；
- 车队推陷在黑路毯里的车辆，路边交通标志转过了头；
- 医院恢复供电，银蚁开始搬走手术钉；
- 北京方案传到成都，低温抑菌只维持了数小时。

异常要改变正在进行的任务，不为“画面很震撼”单独停留。

### 2. 抓住低处信息

林扬不靠灵光一闪。先给读者能回看的东西：

- 蓝花银白叶脉跟随呼吸收缩；
- 透明蛛网只在斜光下闪彩虹；
- 白花尸体耳后有淡红根毛；
- 黑路毯边缘在热天闪孔雀蓝；
- 隧道裂缝、落石、渗水和风向互相矛盾；
- 楼根沿建筑沉降缝而非城门发力。

低处信息转化为动作即可，不必继续证明。通常抓住一两个物件就够，不能把场面摆成证据展台。

### 3. 动作夺回主动

优先使用项目世界内的动作：关灯、开喷淋、撒干粉、敲岩层、测坡、断电、停泵、铺陶瓷、制造不规则振动、切换适应、拖车、关闸、改道。

动作写清：谁在哪里、距离多远、拿什么做、失败会伤到谁。少用“爆发出惊人速度”“气势席卷全场”等抽象强势句。

### 4. 局面发生可见变化

场面结束至少改变一项：

- 人救出来了或没能救出；
- 道路从不可通过变为只有一条车道；
- 水、电、空气中的一项恢复；
- 队伍失去车辆、食物或时间；
- 一种危险被转化为材料、食物或预警；
- 林扬获得信任、队伍或权限；
- 空出的生态位招来下一种生命。

没有变化的追逐、争论和试验应压缩。

## 四、对白回弹

对白要围绕选择，不围绕作者观点。

底层语言必须通俗。人物可以抢话、重复、没说完、没听清，不能为了“对白有力”而句句短、句句准、句句像金句。先保证像真人说话，再保证冲突清楚。

可用结构：

1. 一个人提出最省事或最残酷的办法。
2. 另一个人指出具体代价，不上价值口号。
3. 林扬问一个可执行问题：门能撑多久、车还能开多远、谁来签字。
4. 行动结果证明一部分人对、一部分人错，并留下新的账。

林扬可以有短促的学生气、冷话或自嘲，但不持续讲段子。他最有分量的话通常是承担后果，例如“路我签”“门我关”“我进去，你们把泵开起来”。同类句式不要滥用，必须由前文行动挣来。

## 五、兑现节奏

- 每三至五章一次小兑现：识破伪装、救下具体的人、抢回物资或扭转一次质疑。
- 每十五至二十章一次中型兑现：新适应完成首秀，并换来装备、配给、队伍或指挥权。
- 卷末一次公开大兑现：结果被车队、城市或通信另一端看见。
- 能力首秀不等于本卷结束。后续还要换场景复用，证明它是新战斗方法而非一次性钥匙。

兑现可以是战斗，也可以是让水泵重新转、让错误手册被跨城撤回、让五万人保住一段迁徙路线。男频爽点的核心是人物努力改变了具体命运。

## 六、章末钩子

优先使用本章因果产生的钩子：

- 灯关了，花冠却全部朝向呼吸声；
- 车队刚过桥，油罐车轮胎陷进正在冷凝的路面；
- 低温让银蚁脆裂，也让手术室里的病人开始失温；
- 北京撤回旧版手册，成都当天必须拿出替代方案；
- 林扬找到了母亲，转运名单上却有父亲的死亡日期。

避免：

- “更大的危机还在后面”；
- 无来源的新敌人突然露脸；
- 为断章故意让角色不说完整一句本来能说完的话；
- 每章都以怪物逼近或林扬昏迷收尾。

## 七、正文禁忌

- 不把新物种写成等主角触发的关卡怪。
- 不把结构代价写成发光弱点。
- 不让林扬靠挨打即时获得正好需要的新能力。
- 不让配角只报答案、递武器、喊名字和震惊。
- 不让每场胜利都掉落战利品或触发升级。
- 不用连续排比、单句成段和群众反应制造强行高潮。
- 不把生态规律人格化成“世界针对他”。
- 不用参考作品的专有名词、桥段或原句。

## 八、与其他 skill 的关系

- `webnovel-workflow`负责结构、连续性和同步。
- `novel-de-ai`负责清理模板化表达。
- `human-prose`负责人物、身体与生活质感。
- 本 skill 只负责推进力、主角高光、对白回弹和收益兑现。冲突时以 `CLAUDE.md` 和当前设定为准。
