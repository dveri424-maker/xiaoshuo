# 活人感创作 Skill

本 skill 用于本项目中文无限流灵异小说正文创作、续写和改稿，目标是让文本有活人感、代入感、主角贴身感和真实撞鬼感。

它不负责新增世界观设定，也不替代卷纲与章节细纲。使用时必须服从：

- `CLAUDE.md`；
- `无限流灵异小说剧情设计.md`；
- `全书卷纲.md`；
- 当前卷细纲，目前为 `第一卷章节细纲.md`；
- 既有正文连续性，尤其是前三章形成的林扬口感。

---

## 一、当前项目核心目标

正文要让读者像贴着林扬本人走进旧校舍、听见广播、闻到霉味、摸到潮纸、看见鞋柜一样，而不是听作者站在旁边讲设定、讲怪物、讲爽点。

优先做到：

1. 林扬先进入读者手里；
2. 麻烦从林扬感官和当场利害里砸进来；
3. 异国生活、灵异异常和恐怖压力随动作与物件进入；
4. 林扬的强由误判、怕、硬撑、动作和后果被读者发现；
5. 旁白带林扬本人的脑子、脾气、尴尬和短促吐槽，不带作者解释腔；
6. 前期不提前解释系统、玩家、任务面板、副本机制和世界真相。

---

## 二、林扬贴身视角规则

### 1. 必须使用贴林扬意识流动的第三人称

允许：

- 写林扬先注意到的声音、气味、冷水、疼痛、血迹、鞋、照片、校牌、名单、座位、门把手、手机信号；
- 写他当下的错愕、误判、想走、后悔、语言听不全、临场取舍；
- 写他边怕边做事：拍照、压低手机光、摸合页、用伞尖挑鞋、记住重复词、按住话筒；
- 写他嘴上胡扯，手上办事，怕但不废。

避免：

- 作者站在高处介绍怪物和世界真相；
- 先讲完整机制，再让林扬行动；
- 用旁白替读者总结“这说明”“这意味着”“他意识到”；
- 长时间写林扬看不见、听不见、不能立刻利用的信息；
- 把灵异现场写成安全探案。

### 2. 信息必须从当前场面自然进入

本项目信息入口优先为：

- **感官：** 冷水渗进鞋带、粉笔灰、霉味、电流声里的水声、后颈汗、血味、纸袋潮软、肩伤疼；
- **动作：** 拍照、照楼梯、试门把手、摸合页、用伞尖压灰、翻旧名单、撕照片、按话筒、敲铃；
- **误判：** 以为导航错误、社团活动、试胆、普通校园怪谈，随后被物件和血纠正；
- **语言障碍：** 日语只听懂半句，幸存者说乱、重复、被广播打断；
- **当场利害：** 门打不开、有人被拖走、自己的名字出现在点名册、鞋柜里多出自己的鞋。

禁止大段旁白硬讲：

- “这个世界的灵异规则是……”；
- “玩家体系的本质是……”；
- “旧校舍副本的机制为……”；
- “本章要完成某个爽点/伏笔”。

### 3. 禁止出戏比喻和作者式总结

重点警惕：

- 像、仿佛、如同、好像、似的、宛如等比喻炫技；
- 抽象化句子：命运、棋局、风暴、深渊、潮水、巨兽；
- 作者式总结：所有人都知道、这意味着、这一刻、从此、真正的、读者能看出；
- 恐怖形容词替代场面：诡异、可怕、阴森、毛骨悚然、令人窒息。

改成具体行为和感官：

- 头顶喇叭沙了一下，女声出来了；
- 白鞋鞋口没有灰；
- 点名册上的墨迹还湿；
- 血顺着木纹往下渗；
- 林扬手指停在手机边框上；
- 伞柄被汗弄得发滑。

### 4. 禁止高频短句堆酷感

不能靠连续短句、单词句、硬切镜头制造“冷硬”“装”“酷哥摆拍”。

少用：

- “血。鞋。名单。”
- “不对。很不对。”
- “门关了。广播响了。他完了。”

短句只留给真正的惊醒、判断落点、动作落点和章末钩子。正文主体要让句子随着林扬心理自然流动：看见、停顿、误判、再确认、下决定。

## 三、灵异开章与章节推进结构

### 1. 本项目灵异开章推荐结构

适用于旧校舍、公寓、电车、医院、便利店、神社等前中期灵异章节：

1. 日常异国生活中混入一个不舒服细节；
2. 林扬先找现实解释，甚至想走；
3. 物件异常出现：鞋、照片、车票、病历、小票、钥匙、手机消息；
4. 熟人、门、广播、怪物或现实压力把他逼进局；
5. 他在语言不通、信息破碎和死亡压力下抓低处信息；
6. 怪物实际压迫或出手造成后果；
7. 林扬用动作、试探、物件和嘴碎短句换来一线主动；
8. 章末留下具体物件钩子。

### 2. 第一章风格锚点

后续正文应继承第一章口感：

- 林扬先看地图、看灌木、看旧楼，不急着送死；
- 异常从白鞋、灰、袜底印、照片手腕、信号掉空进入；
- 他先想走，后来被松岛和木门逼进局；
- 松岛说乱、重复、被打断，林扬只记能用的词；
- 林扬吐槽短而贴危险：“这也是社团活动？”“说重点。”；
- 章末钩子落在头顶喇叭和“晚间点名”。

## 四、人物与对白活人感

### 1. 林扬

林扬可以：

- 怕；
- 后悔；
- 误判；
- 受伤；
- 嘴碎；
- 压着恐惧套话；
- 用普通物件和低处信息找活路。

林扬不能：

- 像提前知道副本机制；
- 从头到尾过度从容；
- 用系统提示替代观察；
- 让配角替他定局；
- 长篇讲解怪物机制。

### 2. 配角与 NPC

配角不能像任务机器或设定讲解员。

灵异现场中他们应有：

- 恐惧；
- 隐瞒；
- 误操作；
- 重复话；
- 语言卡顿；
- 自保；
- 私心；
- 对怪谈传闻的错误理解；
- 被广播、脚步声、敲门声打断。

松岛式说法可作为模板：说得很乱、关键词重复、停顿位置异常、被楼上动静打断。

### 3. 对话规则

对话必须服务：

- 试探；
- 套话；
- 威胁；
- 压恐惧；
- 抢物件；
- 挖怪谈破绽；
- 逼对方说出能用的信息。

不要写平问平答式信息传递。林扬的吐槽要短、贴危险、能缓压或压场。

## 五、改稿检查清单

改稿后逐项检查：

1. 前三段是否已经贴住林扬感官、动作或当场麻烦？
2. 设定信息是否从物件、感官、误判、语言障碍或当场利害进入？
3. 是否有作者式总结、爽点总结或读者提示句？
4. 是否有出戏比喻、漂亮恐怖句或镜头说明腔？
5. 是否连续使用短句短词堆酷感？
6. 旁白是否像林扬本人在想，而不是作者在讲？
7. 林扬的强是否由误判、动作、低处信息和现场后果体现？
8. 是否保留林扬“怕但不废，嘴碎但办事”的口感？
9. 是否有明确灵异怪物压迫？
10. 是否有血腥后果或死亡威胁？
11. 是否避免前期系统、玩家、任务面板、副本机制解释？
12. 章末钩子是否具体可见？

## 六、与其他 skill 的关系

- 与 `webnovel-workflow` 同用时，先按工作流确认卷纲、章节功能、怪物压迫、收益和钩子，再由本 skill 约束正文贴身感。
- 与 `novel-de-ai` 同用时，本 skill 优先处理林扬感官、动作、误判和句式；`novel-de-ai` 负责更广义的去 AI 味和流程打散。
- 与 `老嗷文风` 同用时，本 skill 优先保证恐怖压迫和林扬贴身视角；`老嗷文风` 只提供主角中心、嘴碎、低处信息和爽点口感，不能把正文写偏成权力文或喜剧文。
